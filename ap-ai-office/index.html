⚙️ 연결 설정

Apps Script 웹앱 주소와 키를 넣으면 실제 우편함으로 동작합니다. 값은 이 브라우저(localStorage)에만 저장되고 GitHub 공개 코드에는 들어가지 않습니다.

· 주소만 넣고 연결 테스트를 누르면 ?action=ping으로 상태를 확인합니다.

· 링크로 바로 열 때는 #k=AGENT_KEY&api=https://…/exec 형태도 됩니다.

· 배포 방법은 저장소의 apps-script/README.md를 보세요.
